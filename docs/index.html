Reading automation · GitHub Pages

A calmer way to keep up with serial fiction.

Configure one reading queue, batch several chapters together, and deliver a single digest to one or many readers without turning anyone's inbox into a notification feed.

Private by design.
Gmail credentials stay in GitHub Secrets. This page only generates non-secret repository variables and never asks for your password.
1

Choose the source

Paste the novel's table-of-contents or index page.

2

Add readers

Every reader receives an individual copy, so addresses are not exposed to one another.

3

Set the delivery

Control digest size and what the email contains.

Advanced scraper selectors
Selectors vary by website. Links-only mode usually needs the chapter-link selector; full-text mode also needs title/body selectors.
